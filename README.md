# MZ CHATBOX — College Chatbot Website

A neon-style, mobile-responsive college chatbot starter website using your uploaded college logo.

## Run it
1. Extract `MZ_CHATBOX.zip`.
2. Open the `MZ_CHATBOX` folder and tap/open `index.html` in a browser.
3. On a phone, the easiest way to access it is to upload the extracted folder to a static host (for example, GitHub Pages or Netlify), then open the site URL on your phone.

The website is static and does not need a server for its demo replies. It is not connected to a live AI service or college database.

## Customise college answers
Open `script.js`. Edit the `knowledge` list to add the college's verified:
- programme/course details
- admission dates and eligibility
- fees and scholarships
- examination notices
- facilities and office contacts
- placement-cell information

Replace `assets/college-logo.png` to change the logo. Keep the same filename, or update the image path in `index.html`.

## Important before publishing
The included responses are starter guidance, not official college information. Verify every answer with the college before making the site public. Do not put private student data, passwords or confidential records in this front-end demo.

## Files
- `index.html` — page structure
- `styles.css` — neon theme and responsive layout
- `script.js` — demo chatbot responses
- `assets/college-logo.png` — supplied logo
